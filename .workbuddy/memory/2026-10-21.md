# 2026-10-21

## AC-Camera 安卓 App 初版落地

为声学环保工程师（用户）从零搭建安卓 App，覆盖业务闭环：
网格划分 → 格点声压级测量 → 等声压级曲线 → 噪声源反推 → 定向治理 → CSV 导出。

- 代码已推送至 GitHub `E5-lab/AC-Camera`（SSH 推送成功，main 分支，提交 9dd54c1）。
- 技术栈：Kotlin + Jetpack Compose(Material3) + Room(离线优先) + Navigation Compose。
- 声学算法：IDW 反距离加权插值 + Marching Squares 等值线 + 局部极大值噪声源检测。
- 麦克风实时声压级：`AudioRecord` RMS → dB，带校准偏移（默认 90dB，需现场校准）。
- 注意：仓库未提交 gradle-wrapper.jar（二进制），Android Studio 打开会自动生成；沙箱无 Java/Gradle/SDK，未做本地构建（按用户偏好）。
- minSdk 26（用矢量自适应图标，避开 PNG 启动图标）。
